# Propuesta de valor · ULogix × FEMSA Fontibón

ULogix integra retrofit brownfield, simulación, automatización, SCADA, MES/UNS y ERP para convertir la demanda pronosticada en capacidad ejecutable y trazable.

## Alcance diferencial

- Encajonadora custom para cajas 30×30 en L1.
- GANTRY ABB compartido entre L1 y L2, en vez de duplicar una celda completa.
- Variopac usada para conformar paquetes termoencogibles de L2.
- Robot ABB para L3, conservando una llenadora que ya cubre la demanda.
- Llenadoras KRONES usadas en L1/L2 dimensionadas con holgura de capacidad.
- Tecnomatix Plant Simulation, Siemens NX y RobotStudio para validar antes de instalar.
- Ignition SCADA, MES, Coreflux MQTT/UNS y ERP/Odoo para operación y trazabilidad.

## Caso base vigente

| Resultado | Valor |
|---|---:|
| CAPEX total | COP 9.165.554.245 |
| VPN | COP 11.032.069.063 |
| TIR anual efectiva | 78,2 % |
| ROI | 226,7 % |
| Payback simple / descontado | 22 / 25 meses |

La propuesta se evalúa contra el estado anterior —incluido el paletizado manual y su dotación— y contra alternativas comerciales. Las celdas custom se justifican cuando cumplen la cadencia con menor CAPEX e integración compartida; los equipos usados se seleccionan con criterio de condición, soporte, FAT/SAT y costo total instalado.

El archivo `estudio-mercado-inicial-fontibon.md` se conserva como punto de partida. El pronóstico validado está en [`../../pronostico-demanda/`](../../pronostico-demanda/README.md).
